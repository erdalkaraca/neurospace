# ACT-R Third-Party Content

Tutorial texts, Lisp models, and Python task files bundled in this extension are from the
[ACT-R 7 software](https://act-r.psy.cmu.edu/software/) distributed by the ACT-R Research Group,
Department of Psychology, Carnegie Mellon University.

Neurospace does not redistribute the full ACT-R Lisp core. Only the official tutorial subtree
is included for learning and editing purposes.

For ACT-R software terms and support, see https://act-r.psy.cmu.edu/software/

## Lisp syntax highlighting

Monaco language `actr-lisp` is contributed via `@eclipse-docks/extension-monaco-editor`
(`MONACO_GRAMMARS`). It is an ACT-R–oriented Monarch grammar (productions, buffers, bangs,
model forms) inspired by the minimal rules in
[Lisp-Syntax](https://github.com/shenlebantongying/vscode-lisp-syntax) (MIT) /
[bradrobertson/sublime-packages/Lisp](https://github.com/bradrobertson/sublime-packages/tree/master/Lisp).
